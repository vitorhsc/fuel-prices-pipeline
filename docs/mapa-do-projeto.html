3Em três frases, numa entrevista

  • A API da DGEG só mostra o preço atual, por isso o pipeline tira uma fotografia por dia e deteta o que mudou para construir o histórico.
  • Cada fotografia fica guardada em Parquet antes de entrar no PostgreSQL, o que permite reconstruir tudo sem voltar a chamar a API.
  • No PostgreSQL, os dados passam de raw para um modelo em estrela em analytics, pronto para SQL e Power BI.
