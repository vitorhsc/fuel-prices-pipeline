3O projeto em três frasesThe project in three sentences

  • A API da DGEG só mostra o preço atual, por isso o pipeline tira uma fotografia em cada execução e deteta o que mudou para construir o histórico.
  • Cada fotografia fica guardada em Parquet antes de entrar no PostgreSQL, o que permite reconstruir tudo sem voltar a chamar a API.
  • No PostgreSQL, os dados passam de raw para um modelo em estrela em analytics, pronto para SQL e Power BI.
  • The DGEG API only shows the current price, so the pipeline takes a snapshot on every run and detects what changed to build the history.
  • Each snapshot is stored as Parquet before it reaches PostgreSQL, so everything can be rebuilt without calling the API again.
  • Inside PostgreSQL, data moves from raw to a star schema in analytics, ready for SQL and Power BI.
